# iCTRL 独立云构建准备

状态：基线和 Safari 专用 `probe_guarded_tap` 实验均已通过 GitHub Actions Xcode 16.4 编译、打包和身份检查。实验 run `40476648388`，提交 `18aa06c`。当前增量为 `probe_guarded_run` 原生短循环实验，尚待编译和真机验收，**不可接入生产流程**。

新的独立实验包含 `native_job_start/status/cancel`：JavaScriptCore逐步驱动可信的本地生成器脚本。云包只包含通用驱动器，业务脚本和配置由授权客户端在本地提供，不上传此仓库。该入口只接受confirm配置，禁止提交、付款、预约按钮和裸坐标点击；每次触摸用新完整快照定位并复核前台和系统弹窗，不在失败后补点。最多240秒，取消只阻止后续动作，不能撤回已经交给系统的动作；任务状态保存在Probe独立容器，重启标记中断、不自动重放。最近40个请求ID去重；并非任意不可信JavaScript沙箱。截图像素桥及业务场景必须单独真机验收，不能仅以编译通过视为可投入使用。

原生短循环只服务固定 Safari 隔离页面：每次触摸前重新执行完整单次核验，不预排队。最多6次触摸，从方法实际开始执行起3秒内允许发起触摸；达到任一上限或出现停止/错误/不确定结果立即退出。使用服务器本地时钟并同时检查单调时钟期限，避免电脑与手机时钟偏差。RPC排队时间不算在3秒内，正在执行的系统调用不可取消，实际返回时间可能超过3秒；客户端超时后不可重发。该实验不支持长期后台任务或运行中远程取消，也不包含候场业务代码。

实验仅在 Safari 专用页面具备固定标记、16位 nonce、唯一测试按钮且没有停止标记时发起一次触摸。使用同一份 Safari 快照做判断和定位，单独复核系统弹窗；异常、过期或不确定结果停止，不预排队，不补点。页面检查与触摸仍非原子操作。`expires_at_ms` 只限制触摸发起时间，不保证请求在5秒内返回。

将本目录内容作为公开 GitHub 仓库根目录（仅这些文件），手动运行 Actions。标准 macOS runner；私有仓库自动跳过；30 分钟上限；产物保留一天；不需要 Apple ID、证书或手机密钥。上游固定提交，构建时只下载上游公开依赖。

隔离：Bundle 前缀 `org.houchang.ictrlprobe`、端口 `18201`、URL scheme `hc-ictrl-probe` / `hc-ictrl-probe-app`，以及独立密钥存储服务与 Bonjour 标识。包标识检查通过仍不等于真机可并存；iLoader 重签后的身份和安装提示仍须检查，不接受撤销原证书/替换原服务的操作。

本目录不得放入候场代码、配置、账号、配对数据或证书。第一步用它检查免费构建通路和隔离包，再编写条件点击补丁并做独立审核及真机隔离验收；未验收不连接现有候场程序。

隔离基线不打包上游 CLI/Python 客户端和操作指南，它们默认使用原服务的端口/凭据目录；对应下载入口不可用。后续测试客户端必须使用独立凭据文件、显式 Probe 端口，不覆盖手机 `/root/.ictrl`。

独立安装与同时运行是两项验收：不同 Bundle ID 不保证两个 XCTest 服务同时运行互不影响；未完成隔离测试前不启动现有候场购票任务。
